# VDH · Ranking del equipo

App estática (PWA) para GitHub Pages. Ranking semanal en vivo de vendedores y locales VDH.
Consume el mismo endpoint de Apps Script que el dashboard principal.

Separada en su propio repositorio (antes vivía en `/equipo/` dentro del repo del dashboard)
para que cada PWA tenga su propio `scope` y se puedan instalar por separado en el celular
sin que una tape a la otra.

## Publicación

GitHub Pages, rama `main`, carpeta raíz.
